## 3. Foolproof OBS Link Generator & Routing Architecture (CRITICAL)
To guarantee that generated OBS links NEVER return a `404 Not Found` error on Render.com or inside OBS Studio Browser Sources:

1. **Root Query-Parameter Overlay Routing (`window.location.search`):**
   - At the very top of `App.tsx`, inspect `new URLSearchParams(window.location.search)`.
   - **If `params.get('obs') === 'alerts'`:** Render ONLY the transparent **OBS Follower Alert & TTS Overlay Canvas** (`document.body.style.background = 'transparent'`, zero dashboard UI). Read URL query overrides (`&template=`, `&font=`, `&tts=`, `&voice=`, `&sfx=`, `&duration=`) and connect to `GET /api/events?client=obs-alerts` for real-time follower popups, milestone confetti, and animated Text-to-Speech.
   - **If `params.get('obs') === 'counter'`:** Render ONLY the transparent **OBS Follower Counter Overlay Canvas** (`document.body.style.background = 'transparent'`). Read `&template=`, `&font=`, and `&showGoal=` from the URL, and connect to `GET /api/events?client=obs-counter` for real-time follower count updates.
   - **If no `?obs=` parameter is present:** Render the **Private VIP Streamer Dashboard** for `sujalxsaini`.

2. **Interactive "⚡ Generate OBS Link" Builder Component:**
   - Dynamically construct OBS URLs using `${window.location.origin}/?obs=...` so it automatically uses the live `.onrender.com` URL.
   - Whenever the user clicks **"⚡ Generate OBS Link"** on any Alert or Follower Counter template, display a **Streamlabs-Style OBS Link Generator Panel** featuring:
     - **Generated OBS URL Input Box** with a **Privacy Blur Toggle** (eye icon to hide/show the URL when streaming).
     - **"📋 Copy Link for OBS" Button** (one-click copy with visual confirmation).
     - **"↗️ Test Overlay in New Tab" Button** (opens the exact generated `?obs=` link in a new tab to verify transparency and animations).
     - **Live OBS Connection Status Badge:** The backend tracks connected SSE clients (`obs-alerts` and `obs-counter`). Display **`🟢 Connected in OBS (X active)`** on the dashboard the moment the link is opened in OBS Studio!
     - **Recommended OBS Browser Source Settings:** Shows exact `Width x Height` (`850 x 600` for Alerts, `550 x 200` for Counter) and a one-click copyable **OBS Custom CSS** snippet:
       `body { background-color: rgba(0, 0, 0, 0) !important; margin: 0px auto; overflow: hidden; }`

## 4. Backend Server (`server.ts`), Webhook Engine & Real-Time SSE
Implement a complete Express + Vite server in `server.ts`:
1. **Persistent JSON State (`settings.json`):**
   - Stores `channelName` (`"sujalxsaini"`), `channelUrl` (`"https://kick.com/sujalxsaini"`), `pin` (`"1234"`), `followerCount` (`1250`), `followerGoal` (`1500`), `goalTitle` (`"ROAD TO 1.5K FOLLOWERS"`), `alertsPaused` (`false`), `alertsMuted` (`false`), `activeAlertTemplate` (`"neon"`), `activeCounterTemplate` (`"neon"`), `selectedFont` (`"Orbitron"`), `alertDuration` (`7`), `sfxPreset` (`"cyber"`), `customSfxUrl` (`""`), `ttsSettings` (`enabled: true`, `mode: "stream"`, `lang: "en-US"`, `messageTemplate: "{username} just started following sujalxsaini! Welcome to the VIP squad!"`, `rate: 1.0`, `pitch: 1.0`, `volume: 1.0`), `recentFollowers` (array), `webhookLogs` (array of recent incoming webhook requests with timestamp, event type, and payload for the live debugger), and `setupChecklist` (progress tracker for the Zero-to-Everything guide).
2. **Server-Sent Events (`GET /api/events`):**
   - Tracks client types via `?client=dashboard`, `?client=obs-alerts`, or `?client=obs-counter`.
   - Broadcasts `STATE_INIT`, `SETTINGS_UPDATED`, `FOLLOW_ALERT`, `CUSTOM_TTS_ANNOUNCE`, `MILESTONE_REACHED`, `WEBHOOK_RECEIVED`, `QUEUE_CONTROL`, and `OBS_STATUS_CHANGED`.
3. **Kick Official Webhook Endpoint (`POST /api/webhook/kick`) & Webhook Simulator (`POST /api/webhook/simulate`):**
   - Accepts official Kick `channel.followed` webhook POST requests (supporting headers like `Kick-Event-Type: channel.followed` and extracting follower username from `req.body?.follower?.username || req.body?.data?.follower?.username || req.body?.username || "KickUser"`).
   - Logs every incoming webhook call into `webhookLogs` (timestamp, headers, payload, status) and broadcasts `WEBHOOK_RECEIVED` so the user can see live webhook traffic in the Dashboard's **Webhook Inspector**.
   - Increments `followerCount` by 1, adds to `recentFollowers`, and broadcasts `FOLLOW_ALERT` to all connected OBS overlays.
   - **Automatic Goal Milestone Trigger:** If the new `followerCount` equals `followerGoal`, automatically broadcast `MILESTONE_REACHED` so OBS fires a full-screen confetti & fanfare celebration.
   - Always responds with `200 OK` (`{ received: true }`) immediately so Kick never disables the webhook.
4. **Health & Keep-Alive Endpoint (`GET /api/health`):**
   - Returns `{ status: "ok", channel: "sujalxsaini", uptime: process.uptime() }` so Render.com or UptimeRobot can keep the service awake 24/7.
5. **Multi-Accent OBS Text-to-Speech Proxy (`GET /api/tts`):**
   - Accepts `?text=...&lang=...` (supporting `en-IN` Indian English, `hi-IN` Hindi, `en-US` US English, `en-GB` British English, `ja-JP` Japanese, `es-ES` Spanish).
   - Fetches and streams `audio/mpeg` from `https://translate.google.com/translate_tts?ie=UTF-8&q=${encodeURIComponent(text)}&tl=${lang}&client=tw-ob` so OBS Browser Sources play crystal-clear TTS via standard HTML5 `<audio>`. Also support Browser `window.speechSynthesis` as an optional toggle.
6. **Synthesized Polyphonic Web Audio API Sound Effects:**
   - Build a synthesizer utility using `AudioContext` with **6 Premium Alert Sound Presets** (`cyber`, `royal`, `valorant`, `anime`, `glass`, `arcade`) so every alert plays a crisp polyphonic sound effect before the TTS speaks.
